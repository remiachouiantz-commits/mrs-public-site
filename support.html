Support MRS

Pour une question, un incident, un signalement impossible depuis l'application ou une difficulté à supprimer votre compte, écrivez à mrs.support21@gmail.com.

Pour nous aider, indiquez le modèle de téléphone, la version de l'application, l'écran concerné et une description du problème. N'envoyez pas de mot de passe, de code de connexion, de trace GPS, de conversation privée ou de données d'un tiers.

En V1, vous pouvez demander la suppression de votre compte ; aucune suppression automatique pour inactivité n'est active.

Si vous avez accès à l'application, vous pouvez utiliser Profil > Support. Pour la suppression, consultez également la page dédiée. Pour vos droits sur les données, consultez la politique de confidentialité ; l'adresse pour exercer ces droits est aussi mrs.support21@gmail.com.

Les messages envoyés au support sont conservés pendant le traitement de la demande, puis seulement pour le suivi réellement nécessaire. Les informations devenues inutiles sont supprimées.
